# 🔗 LinkShare
> Essa ferramenta/script seleciona produtos de diversas lojas de maneira manual/automatizada e redireciona para trafego social, utilizando ia, para a complementação direta

## 🛠️ Tecnologias
* **Python 3.x.x** - Manipulação das API
* **Flask** - Framework backend python
* **IA (ainda estou escolhendo o modelo)** - Criação de dados de forma automatica e a filtragem de dados
* **Git e GitHub** - Para o historico e o armazenamento do projeto

## 📋 Pré-requisitos
* **[Git](https://git-scm.com/)**
* **[Python 3.x.x](https://www.python.org/downloads)**

## 🚀 Como Executar
```bash
# Clone esse repositorio
$ git clone https://github.com/jjonasxd/linkshare.git

# Acesse a pasta
$ cd linkshare

$ python3 -m venv venv

# Ativar o ambiente virutal

# Linux
$ source venv/bin/activate

# Windows
$ venv\Scripts\activate.bat

# pip install -r requirements.txt

# Execute
python3 run.py
```
